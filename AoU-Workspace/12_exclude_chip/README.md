# 12 – CHIP Variant Identification and Exclusion

## Overview

This directory contains the workflows used to identify and exclude variants associated with clonal hematopoiesis of indeterminate potential (CHIP) from downstream genetic association analyses.

The objective is to assess the potential contribution of CHIP-associated variants to observed gene-based association signals in acute myeloid leukemia (AML). The workflow uses Hail to perform variant-level quality control, identify CHIP-associated variants, and generate filtered genomic datasets for subsequent association analyses.

## Workflow

The notebooks are organized sequentially according to the following steps:

| Notebook | Description |
|---|---|
| `12_01_hail_chip_variant_qc.ipynb` | Perform variant-level quality control using Hail to prepare genomic data for CHIP variant identification. |
| `12_01_hail_chip_variant_qc.ipynb` | Perform variant-level quality control using Hail to prepare genomic data for CHIP variant identification. |
| `12_02_hail_chip_exclusion.ipynb` | Identify variants to be considered for exclusion based on CHIP-related criteria. |
| `12_03_hail_chip_remove_variants.ipynb` | Remove variants identified through allele balance and read depth filtering from the genomic dataset. |
| `12_04_hail_chip_reporting.ipynb` | Generate summary reports documenting the identified CHIP-associated variants and their exclusion. |
| `12_05_hail_filter.ipynb` | Reapply variant-level quality control to the genomic dataset after excluding variants using allele balance and read depth filtering procedures. |
| `12_06_hail_missing_check.ipynb` | Assess missingness following variant filtering and exclusion. |
| `12_07_hail_update.ipynb` | Update variant identifiers in the genomic dataset following the preceding filtering and quality-control procedures. |
| `12_08_hail_chip_hotspots.ipynb` | Identify and exclude established CHIP-associated hotspot variants. |

## Environment Configuration

The following notebooks support environment configuration and execution within the All of Us Researcher Workbench:

- `Environment_DSUB.ipynb`: Configuration and execution of computational workflows using the AoU `dsub` infrastructure.
- `Setting_Env_Variables.ipynb`: Definition of environment variables required by the analysis scripts.

## Execution

The notebooks should generally be executed in numerical order, beginning with `12_01_hail_chip_variant_qc.ipynb` and proceeding through the subsequent steps.

Environment configuration should be completed before submitting computational workflows.

The outputs generated by this directory are used in the downstream gene-based association analyses that exclude CHIP-associated variants.
