# Table of Contents 

## 1. **Bulk RNA-Seq Analysis** 
  - This directory contains scripts for processing and analyzing bulk RNA-seq data from the NCI Genomic Data Commons (GDC) AML cohort. The workflow includes quality control, gene expression normalization, survival analysis, principal component analysis (PCA), and differential expression analysis. Generated gene sets are used in downstream rare variant polygenic risk score analyses.

## 2. **Single-Cell RNA-Seq Analysis (GSE116256)**
  - This directory contains scripts for processing and analyzing single-cell RNA-seq data from GSE116256, comprising 16 AML and 5 healthy bone marrow samples collected at diagnosis. The workflow includes quality control, normalization, doublet removal, data integration, and cell type–specific differential expression analysis to generate upregulated and downregulated gene sets for downstream rare variant polygenic risk score analyses.
