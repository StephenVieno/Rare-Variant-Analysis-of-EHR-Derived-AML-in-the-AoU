# Bulk RNA-Seq Quality Control 
### RNA-Seq-QC-Normal-Tissue.R
Performs quality control checks on RNA-Seq data from normal tissue. Includes read count summaries, mapping statistics, and visualization of data quality metrics.
### RNA-Seq-QC-Primary-Tumour-Bone-Marrow.R
Performs quality control on RNA-Seq data from primary tumor samples in bone marrow. Ensures data integrity before downstream analyses.
### RNA-Seq-QC-Primary-Tumour-Peripheral-Blood.R
Conducts quality control on RNA-Seq data from primary tumor samples in peripheral blood. Includes visual and statistical checks for data reliability.

# Differential Gene Expression Analysis 
### RNA-Seq-Differential-Expression-Analysis.R
Performs differential gene expression analysis on RNA-Seq data. Includes normalization, filtering, and statistical testing to identify genes with significant expression differences between experimental groups.
### RNA-Seq-Differential-Expression-PCA.R
Conducts principal component analysis (PCA) on RNA-Seq expression data. Used to visualize sample clustering, detect batch effects, and explore patterns in the dataset prior to downstream analyses.

# Cox Regression Gene Expression Analysis 
### RNA-Seq-Normal-Tissue-Cox-Regression.R
Performs Cox proportional hazards regression analysis on RNA-Seq data from normal tissue samples. Evaluates associations between gene expression levels and survival outcomes.
### RNA-Seq-Primary-Tumour-Bone-Marrow-Cox-Regression.R
Conducts Cox regression analysis on RNA-Seq data from primary tumor samples in bone marrow. Assesses gene expression as a predictor of patient survival.
### RNA-Seq-Primary-Tumour-Peripheral-Blood-Cox-Regression.R
Performs Cox proportional hazards analysis on RNA-Seq data from primary tumor samples in peripheral blood. Evaluates the impact of gene expression on survival outcomes.
